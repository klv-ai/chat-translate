# chat-translate
Translation service for small text chunks designed to augment a multi-lingual messaging system

This software uses a machine learning model from Google, whose license is also included in this repo. Users must agree to be bound by it's terms and conditions. (Gemma translate license)[./GEMMA-LICENSE.md]


Online translate service at (DeepL)[https://www.deepl.com/en/pro] €25/month for 1M characters, €50/month unlimited. Has a free tier for development capped at 50K characters per month.
