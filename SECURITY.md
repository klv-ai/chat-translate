# Security Policy

## Supported versions

Only the latest release on `main` is supported.

## Reporting a vulnerability

Email **security@klv.ai** with:
- a description of the issue and its impact;
- the steps, requests or code needed to reproduce it;
- any affected endpoints, versions or configuration.

Do not open a public issue or discuss the vulnerability publicly until it has been
fixed. We will acknowledge the report and keep you informed while we investigate
and fix it.
